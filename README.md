# Midsummer Milano — Shopify theme

A Shopify Atelier 4.1.5 theme customised for Midsummer Milano, turned from a Claude Design
export into an upload-ready theme.

- `midsummer-atelier-theme-final.zip` — upload as-is: Online Store → Themes → Add theme → Upload zip file.
- `theme/` — the same theme as source files (the folders Shopify expects at the root of the zip).
- `INSTALL.md` — setup steps after upload: Files, pages, menus, metafields, media, settings.
- `CHANGES.md` — everything fixed relative to the original export, and why.
